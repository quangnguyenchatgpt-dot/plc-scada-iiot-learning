## Fixed schedule
104 weeks × 3 sessions per week × 2 hours = **312 sessions / 624 hours**. Monday / Wednesday / Friday; other days off or optional review.

## Five workbook tabs
1. `Daily Plan` — each study session, exercises, evidence and resource links.
2. `Weekly Roadmap` — 104 weekly topics and planned hours.
3. `Resources` — curriculum resource catalog including Wokwi, Espressif and industrial docs.
4. `Projects & Rubric` — project milestones and deliverables.
5. `Overview` — duration, scope and assumptions.

## Version control policy
The Excel file committed here is a **snapshot**, not a live synchronization. Google Sheets may contain progress/status edits after this commit. Do not overwrite real progress with an older Excel snapshot.

When revising the syllabus, update Google Sheets, export to XLSX and commit a new snapshot. Review changes (topic, session counts, week sequence and resource links) before merging. Keep student submissions and scores under learner control. Never claim synchronization occurred without actually performing it.
