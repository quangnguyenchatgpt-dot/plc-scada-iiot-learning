| Ngày | 120 phút | Đầu ra |
|---|---|---|
| Thứ Hai | 20' ôn + 45' đọc + 45' ví dụ + 10' ghi chú | Hiểu nguyên lý |
| Thứ Ba | 15' ôn + 75' bài tập + 20' kiểm tra + 10' lưu | Bài giải |
| Thứ Tư | 20' ôn + 45' chủ đề mới + 45' ví dụ + 10' ghi | Sơ đồ/code |

| Thứ Sáu | 20' ôn + 60' tích hợp + 30' quiz + 10' tổng kết | Mini-project, ≥80% quiz |

## Nguyên tắc
- Đọc đúng chương/mục liên quan; không cần hoàn thành cả giáo trình.
- Đặt giả thuyết **trước** khi chạy mô phỏng; so kết quả thực nghiệm và dự đoán.
- Mỗi lab tối thiểu có các case normal, boundary, fault khi phù hợp.
- Lưu mã nguồn và bằng chứng; không commit mật khẩu, token hoặc dữ liệu nhạy cảm.
- Chỉ chuyển bài khi có thể giải thích nguyên lý và tái lập kết quả.
