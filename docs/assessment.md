# Tiêu chí đánh giá

| Tiêu chí | Trọng số |
|---|---:|
| Nắm khái niệm và giải thích đúng | 20% |
| Bài tập và độ chính xác | 25% |
| Mô phỏng / code tái lập được | 30% |
| Test case và xử lý lỗi | 15% |
| Tài liệu / nhật ký | 10% |

Đạt **≥75/100**, không bỏ qua yêu cầu an toàn. Với tuần không có phần mềm mô phỏng phù hợp, thay bằng bài tính toán và Python notebook có kiểm chứng.

## Checklist
- [ ] Có nguồn học và trang/chương đã tham khảo
- [ ] Có bài giải, chú thích đơn vị đo
- [ ] Có file mô phỏng hoặc code chạy được
- [ ] Có expected vs actual và nhận xét sai lệch
- [ ] Có ít nhất một trường hợp biên/lỗi
